Loot Ledger

Look up any WoW: Forever character through the official Blizzard API. You'll get their gear, stats, talents, professions, reputations, achievements, raid progress, collections and everything else the API returns.

Find a Character

Forever doesn't show realms, so each character's realm is hidden. Leave Realm on Auto-detect and every realm in your region is searched; if more than one character has the name, you pick from the list. If you type a surname, only the first word (the character name) is used in the lookup, and the surname is then used to narrow the matches.

Use your own Blizzard API credentials (optional) using site API

You don't need this: by default, lookups go through this site's own API proxy, which has its own Blizzard key. Fill these in only if the site API is down or rate-limited. Then your browser calls Blizzard directly with your own free API client from develop.battle.net ↗. Your credentials are sent only to oauth.battle.net and are kept in this tab's session storage, unless you tick "remember".

If the browser blocks the token request, make a token in a terminal and paste it here (it lasts about 24h):
curl -u CLIENT_ID:CLIENT_SECRET -d grant_type=client_credentials https://oauth.battle.net/token

Advanced: API proxy & namespaces

Blizzard hasn't documented the Forever API yet. These defaults (profile-forever-{region} and dynamic-forever-{region}) come from community testing. If Blizzard changes them, update them here; your changes are saved in this browser. Use {region} as a placeholder.
